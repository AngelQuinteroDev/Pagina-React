# Pagina React

Single Page Application (SPA) basica creada con **React + Vite** para la Semana 1: crear tu primera app con React y desplegarla en Vercel.

## Caracteristicas

- Proyecto creado con React + Vite.
- SPA con componentes reutilizables (Header, Hero, Features, About, Footer).
- Estilos propios con CSS responsive.
- Desplegada como SPA estatica en Vercel.

## Comandos

```bash
npm install        # instalar dependencias
npm run dev        # servidor de desarrollo
npm run build      # build de produccion
npm run preview    # previsualizar el build
npm run lint       # ejecutar linter (oxlint)
```

## Componentes

La interfaz esta compuesta por varios componentes en `src/components/`:

- `Header.jsx` — navegacion superior.
- `Hero.jsx` — seccion principal.
- `Features.jsx` — tarjetas con caracteristicas.
- `About.jsx` — descripcion del proyecto.
- `Footer.jsx` — pie de pagina con enlaces.

## Despliegue

La aplicacion esta publicada en Vercel.
